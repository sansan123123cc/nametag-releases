이름표 v4 · 정밀 검수 서버 (MK5)
================================
편집기 ⚙ 칠하기 설정 → [파이썬 정밀 검수] 를 켜면 껍데기가 이 폴더의 server.py 를
train\venv 파이썬으로 띄운다. 평소엔 안 돈다. 앱을 끄면 같이 꺼진다.

필요한 것
- 메뉴 [학습 → 1. 환경 설치] 한 번 (ultralytics + CUDA torch · RTX 50xx 는 cu128)
- 모델 .pt 파일: 데이터 폴더 models\ 또는 train\base\ 에
  ntd11_anime_nsfw_segm_v5.pt (animeNSFWDetection_v50.zip 안) · variant1 을 받았으면 같이 넣으면 투표에 들어감
  학습본(train\runs\*\weights\best.pt, train\out\*.pt)은 자동으로 목록에 뜸

하는 일
- 입력 1280 (설정에서 1024/1280/1536)
- TTA: 원본 + 좌우 뒤집기 + 1.25배 확대를 다 보고 같은 자리끼리 합침
- 모델 투표: 체크한 모델 전부 돌려서 "합집합"(하나라도 찾으면 있음) 또는 "2개 이상"(혼자 찾은 건 60% 넘어야)
  모양은 과반 픽셀(중간값)
- 결과는 편집기의 애니 seg 결과와 같은 형식 → 그대로 칠하기·영상 검열에 쓰임

문제 생기면 server.log 를 보거나 메뉴 [학습 → 정밀 검수 서버 로그 열기]
