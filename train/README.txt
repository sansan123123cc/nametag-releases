이름표 v4 · 학습(미세조정) 안내
================================

목적: 함장이 칠하고 고친 결과로 애니 seg 모델(ntd11 v5)을 함장 그림체에 맞게 이어서 학습한다.
결과 모델은 models\ 폴더로 들어가고, 편집기가 자동으로 쓴다.

[준비물]
- NVIDIA 그래픽카드(권장, VRAM 8GB 이상). 없으면 CPU로도 되지만 매우 느리다.
  RTX 50xx(블랙웰)는 CUDA 12.8용 torch가 필요 → 1_환경설치.bat 이 cu128 로 깐다. 드라이버는 최신으로.
- 기본 모델 파일: ntd11_anime_nsfw_segm_v5.pt  (animeNSFWDetection_v50.zip 안에 있음)
  → 이 폴더(train\) 안 base\ 폴더에 넣는다.  예: train\base\ntd11_anime_nsfw_segm_v5.pt
- 학습 자료: 편집기 ③ 정리 탭 → [학습 모드] (MK4 · 권장).
    사진마다 모델이 잡은 영역이 테두리로 보인다.
    · 그대로 두면 맞음  · 클릭(우클릭)하면 "잘못 잡음" → 정답에서 뺀다
    · 안 잡힌 데는 붓(B)/네모(R)로 칠하면 "놓침" → 정답에 넣는다
    · Enter = 확정 저장 · Space = 건너뜀 · 1~5 = 부위
    images\ 와 masks\ 에 쌓이고, 잘못 잡음은 "그 자리엔 없음"으로 배워서 과칠이 준다.
  [그대로 내보내기]는 표시 없이 지금 박스를 정답으로 쓴다 (덜 정확).
  최소 100장, 권장 300~500장. 놓침이 많은 유형(전신·작게 나온 부위)을 일부러 많이 넣어라.

[학습 모드] 메뉴 [학습 → 학습 모드 열기] → 따로 뜨는 창에 사진·폴더를 넣고 표시 (MK5부터 본 작업과 분리).
[정밀 검수] 1. 환경 설치가 끝나면 편집기 ⚙ 칠하기 설정 → [파이썬 정밀 검수] 를 켤 수 있다 (infer\README.txt).

[순서] 메뉴 [학습]에서 차례로
 1. 환경 설치  — Python 3.10~3.12 를 찾고, 없으면 winget 으로 3.11 을 자동 설치한다 (안 되면 python.org 에서 직접).
                 venv 만들고 torch(CUDA) + ultralytics 설치. 10분쯤.
 2. 학습 시작  — masks → YOLO 라벨 변환 → 학습(기본 40 epoch, 1024) → ONNX 변환까지.
                 500장 기준 그래픽카드로 1~2시간. 창을 닫으면 멈춘다.
 3. 모델 넣기  — 결과 onnx 를 models\ 로 복사. 편집기 새로고침하면 바로 쓴다.
                 이전 모델은 models\_이전\ 에 남는다.

[설정] train.py 위쪽 숫자(EPOCHS, IMGSZ, BATCH)를 메모장으로 고치면 된다.
[주의] 미세조정한 모델은 개인 사용 용도로만 쓴다(원본 모델 라이선스 표시 없음).
